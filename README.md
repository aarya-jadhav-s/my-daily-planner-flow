# 📚 StudyFlow

A simple daily planner built with Python and Streamlit.

## Features
- Write your own timetable every day (start time, end time, activity)
- Edit or delete any entry
- Mark entries as study / office work and track them against a daily target (default 11 hours)
- Check off sessions on the dashboard and watch your progress
- Copy yesterday's plan with one click
- Data saved automatically in a local JSON file

## Run locally
pip install streamlit
streamlit run studyflow.py
